What it does

Built for people who just want to play.

Every feature exists because setting up Minecraft the normal way is annoying.

Java, bundled Java

Ships with its own Java 25 runtime and finds the right version automatically — no manual JDK installs.

Bedrock, one click

Detects your Bedrock install and launches it straight from the same window as Java.

Microsoft sign-in

Standard device-code login. Your account stays local — nothing leaves your machine but the login itself.

Instances that stick

Keep separate setups for modded, vanilla, or a friend's server — switch between them without losing configs.

Mods, toggled not lost

Turn mods on and off per instance without touching a file explorer. Delete cleanly when you're done.

Always current

Checks the Mojang manifest on launch so new releases show up in your version list automatically.
